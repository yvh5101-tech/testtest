# Daily English

간단한 영어 단어 학습용 웹 페이지입니다.

## 기능

- **단어 카드**: 영어 단어, 발음기호, 뜻, 예문(한·영)
- **발음 듣기**: 브라우저 TTS로 영어 발음 재생
- **퀴즈**: 뜻 고르기 문제와 점수 확인

## 실행 방법

1. `index.html` 파일을 브라우저로 엽니다.
2. 단어 카드로 학습한 뒤, 퀴즈 탭에서 확인해 보세요.

별도 설치나 서버가 필요하지 않습니다.

## 파일 구성

```
.
├── index.html   # 학습 페이지 (HTML/CSS/JS)
└── README.md
```
